# BU Bench V1: codex gpt-6.1-sol with browser-cmd

Run of 31 October 2026. Tasks are named by id and described only in general terms, because the benchmark asks that
decrypted tasks not be published.

## Summary

| Judge | Passed | As judged |
| --- | ---: | ---: |
| GPT-5.5 | 96 / 100 | 97 |
| Gemini 2.5 Flash | 96 / 100 | 97 |
| gpt-5.6-sol | 94 / 100 | 95 |
| Claude Opus 5.5 | 89 / 100 | 89 |

Thirteen tasks failed under at least one judge. Two failed under all four, so they are not a matter of judge
strictness. Every miss is listed below.

## Misses

### Failed by all four judges

| Task | What happened |
| --- | --- |
| `0a58ebe0` | A property listing site refused the browser with a 403 and a press-and-hold challenge that never cleared. The agent reported this and delivered no listings. |
| `d61e1671` | A shopping site showed a security check and then sent the search to a sign-in page. No credentials were available, so no products were returned. |

These are blocks by the sites, not interaction failures. Identical blocks hit plain Chrome without automation from
the same address, so the blocking is not specific to browser-cmd. On one site, WebKit passed where Chrome did not;
we did not identify the signal behind that.

as an outlier.

## Notes on specific tasks

`39272ced` reached the 3,600-second limit, with its answer already written. All four judges accepted it and it is
counted. Under a rule that fails any task at the limit, each score drops by one.

`e876e436` is counted as passed under GPT-5.5 and gpt-5.6-sol, as judged, although the failure above applies to it
in substance.

## Limitations

- **Our own run.** BU Bench V1 has no official leaderboard, and nobody outside this project has checked this result.
- **Live sites.** Results depend on what the sites served on the day and on address reputation.
- **Judge variation.** The same trajectories score between 89 and 96 by judge.
- **Evidence is private.** The benchmark's rules keep trajectories out of this repository, so the verdicts cannot be
  re-derived from public data. `scripts/verify.py` recounts the published verdicts; it does not re-judge.
- **Comparisons are indicative only.** Other published scores come from different models, browsers, dates and judges.
- **The judge is a port.** It uses the benchmark's prompts over a shell trajectory, keeping head and tail, and removes a
  leading `FINAL:` label from answers.
